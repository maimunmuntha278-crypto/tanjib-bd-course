# Tanjib BD — কোর্স ল্যান্ডিং পেজ (সম্পূর্ণ প্রজেক্ট, জিরো-কনফিগ ভার্সন)

আপনার আগের প্রজেক্টের কাঠামো অনুসরণ করে এই নতুন প্রজেক্টটি তৈরি করা হয়েছে —
নতুন নাম ("Tanjib BD"), নতুন পেমেন্ট নম্বর, এবং আপনার Telegram বট টোকেন ও চ্যাট আইডি
সরাসরি কোডেই বসানো আছে। **শুধু আপলোড করলেই কাজ করবে, আলাদা করে কোনো সেটিং বসাতে হবে না।**

## ফাইল স্ট্রাকচার

```
tanjib-bd-course/
├── index.html                     ← মূল ওয়েবসাইট (FAQ + পেমেন্ট + ফর্ম)
├── admin.html                     ← হালকা অ্যাডমিন কন্ট্রোল পেজ
├── netlify.toml                   ← Netlify কনফিগ
└── netlify/functions/notify.js    ← ফর্ম সাবমিট → Telegram এ পাঠানোর সার্ভার ফাংশন (টোকেন এখানেই বসানো আছে)
```

## ⚠️ একটামাত্র জিনিস অবশ্যই মাথায় রাখবেন

**GitHub-এ রিপো বানানোর সময় অবশ্যই "Private" সিলেক্ট করবেন — "Public" না।**

কারণ: আপনার Telegram বট টোকেন এখন `netlify/functions/notify.js` ফাইলের ভেতরে লেখা আছে।
এই ফাইলটা সার্ভার সাইডে চলে বলে ওয়েবসাইট ভিজিটররা কখনো এটা দেখতে পারবে না
(এমনকি "View Page Source" করলেও না)। কিন্তু GitHub রিপো যদি Public থাকে, তাহলে যে কেউ
সরাসরি আপনার GitHub পেজে গিয়ে কোড ব্রাউজ করে টোকেনটা দেখে ফেলতে পারবে। তাই রিপো Private
রাখলেই আপনি সম্পূর্ণ নিরাপদ, আর কিছু করার দরকার নেই।

(অন্য টুকিটাকি নোট — জরুরি না, শুধু জানার জন্য:
রকেট নম্বর `017147747081` (১২ ডিজিট) ঠিকভাবেই বসানো আছে।
admin.html-এর লগইন হালকা প্রোটেকশন মাত্র, আসল নিয়ন্ত্রণ হবে Telegram বটের মাধ্যমে।)

## 🚀 ডিপ্লয় করার ধাপ (কোনো Environment Variable বসাতে হবে না)

### ধাপ ১: GitHub-এ Private রিপো বানান ও ফাইল আপলোড করুন
- github.com এ গিয়ে "New repository" ক্লিক করুন
- নাম দিন `tanjib-bd-course`, **Private** সিলেক্ট করুন, Create করুন
- "uploading an existing file" এ ক্লিক করে এই ফোল্ডারের সব ফাইল ও ফোল্ডার (netlify ফোল্ডারসহ) drag করে দিন
- "Commit changes" ক্লিক করুন

### ধাপ ২: Netlify দিয়ে ডিপ্লয় করুন
- netlify.com এ GitHub দিয়ে লগইন করুন
- **Add new site → Import an existing project → GitHub** সিলেক্ট করুন
- আপনার `tanjib-bd-course` রিপো সিলেক্ট করুন
- কিছু বদলানোর দরকার নেই — সরাসরি **Deploy site** চাপুন

### ধাপ ৩: টেস্ট করুন
Netlify যে লিংক দেবে (যেমন `something.netlify.app`) সেখানে গিয়ে ফর্ম পূরণ করে সাবমিট করুন —
কিছুক্ষণের মধ্যে আপনার Telegram চ্যাটে নোটিফিকেশন আসা উচিত। ব্যস, এতটুকুই!

## নিজের মতো পরিবর্তন করতে চাইলে

- **নাম্বার বদলাতে:** `index.html`-এ `numBkash` / `numNagad` / `numRocket` এবং সংশ্লিষ্ট
  `data-copy` ভ্যালু বদলান।
- **WhatsApp নম্বর বদলাতে:** `index.html`-এর নিচের দিকে `<script>` ট্যাগে
  `WHATSAPP_NUMBER` ভ্যারিয়েবল বদলান।
- **লোগো বদলাতে:** হেডারের SVG কোড বদলে নিজের লোগো (PNG/SVG ফাইল) দিয়ে replace করুন,
  অথবা আমাকে বললে আরও ২-৩টা লোগো ডিজাইন করে দিতে পারি।
- **বট টোকেন বদলাতে হলে** (যেমন কখনো রিভোক করে নতুন টোকেন নিলে):
  `netlify/functions/notify.js` ফাইলে উপরের দিকে `DEFAULT_BOT_TOKEN` লাইনটা বদলান।
